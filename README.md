# Dragon Lore

Dragon Lore é um guia cultural responsivo sobre cultura chinesa. O projeto reúne conteúdos de história, serviços úteis, curiosidades, culinária, turismo e tradições.

## Estado atual

O projeto está na Fase 3 e é desenvolvido com HTML5, CSS3 e JavaScript puro. Os conteúdos fazem parte de uma base local; não há backend, autenticação, usuários ou área administrativa.

## Funcionalidades disponíveis

- Navegação por seis categorias culturais.
- Busca global e filtros por cidade e categoria.
- Cards com detalhes e conteúdos relacionados.
- Favoritos salvos no navegador.
- Compartilhamento de conteúdo.
- Links de localização para itens que os possuem.
