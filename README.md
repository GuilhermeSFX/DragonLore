# Dragon Lore

Dragon Lore é um guia cultural responsivo sobre cultura chinesa, construído com HTML5, CSS3 e JavaScript puro. O projeto apresenta uma experiência exploratória com conteúdo local, navegação por categorias e interações de usuário armazenadas no navegador.

## O que o projeto entrega

- Página inicial com cartões de categoria e status do explorador.
- Página de conteúdos com busca global, filtros por cidade e categoria.
- Modais de detalhe com descrição completa, tags e conteúdos relacionados.
- Favoritos salvos em `localStorage` e listagem dedicadas na home.
- Compartilhamento via API Web Share ou cópia de link.
- Controle de apelido do usuário, contagem de favoritos e último item descoberto.
- Links de localização disponíveis para itens de turismo e serviços.

## Páginas principais

- `index.html`: home do projeto com navegação por categorias, favoritos e painel de status.
- `conteudos.html`: página de exploração com busca, filtros e listagem de itens culturais.
